## Layout

Each assignment folder holds its MATLAB sources (`*.m`, `*.mlx`), generated figures in
`images/`, the write-up as `README.md`, and the submitted PDF. Assignment 1's problem
statement and the source papers it draws on are in `assignment1/refs/`.

## Reference textbooks

`books/` holds Proakis, Tse & Viswanath, and Rappaport. It is **not tracked** — the PDFs are
large, so they live on disk only and are excluded via `.gitignore`.
